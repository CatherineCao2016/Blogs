# Blogs — staging site for Kiro content

A staging site for Kiro guides, blog posts, and other content, published before
it goes anywhere official. Drafts live here so they can be written, reviewed, and
previewed as real web pages first.

Posts are written in Markdown and built into a static site (a home page plus one
page per post) with view analytics.

Developer notes — how to build, add a post, embed media, and deploy — are in
[`DEVELOPING.md`](./DEVELOPING.md).
